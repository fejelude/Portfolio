# Super Mario Odyssey — Childhood Memories (2017)

The collection contains 21 owner-approved gameplay screenshots in the existing 17-location and 4-story-moment sequence. The manifest records the filename, caption, original dimensions and SHA-256 checksum of every local WebP. Thumbnails fit within the existing grid cards at their original aspect ratios. The shared lightbox loads local Mario photos even when their thumbnails are outside the viewport.

Run `node --test tests/mario-gallery.test.mjs` from the repository root. The browser smoke test in `verification/mario-gallery-smoke.cjs` checks the supplied image dimensions, responsive layout, and lightbox interactions.
