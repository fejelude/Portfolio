# Roblox creations image provenance

The two WebP files are compact, 240 × 134 pixel preview crops of the exact owner-provided screenshots of the Roblox game listings. No images were downloaded from search engines and no AI-generated artwork was substituted for the screenshots. The preview crops preserve the artwork and the carousel indicator shown in the provided images. They are intentionally small due to the available upload transfer path. The owner can replace them with the higher-resolution versions of the same crops at these exact paths without changing markup.

- dream-garage-tycoon.webp: screenshot of Dream Garage Tycoon, provided by the owner.
- build-to-impress.webp: screenshot of Build to Impress, provided by the owner.

The full original JPEG files and higher-resolution crops were prepared separately for the owner. The small pixel motifs in the page markup are original decorative vector illustrations, not game screenshots. No live Roblox statistics or game URLs have been inferred. Only the existing, owner-linked Roblox profile is used until direct links are provided.
