# Roblox creation assets
The two WebP images are complete proportional copies of the newly supplied Roblox listing screenshots (Dream Garage Tycoon 937 × 914, Build to Impress 966 × 916). The committed transfer copies are 360 × 351 and 360 × 341 respectively. No crop, substitute artwork, image search or live stats were used. The visible listing statistics are historical screenshot content, not live measurements. Full-size WebP versions are available in the separately delivered asset pack and can replace the two files without changing layout; update the intrinsic width/height attributes to match. Original custom vector scenes are drawn inline, with continuous CSS motion only while visible and motion allowed. Direct experience share links were supplied by the website owner. No third-party animation library is used.
