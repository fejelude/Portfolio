# Sofra — Sakura Kawaii Ambient VFX

## Art direction
A dusky hanami garden framing the existing project card: strawberry-cream highlights, sakura and rose pink, lavender, pearl white and a restrained baby-blue sparkle. Original hand-plotted pixel matrices depict notched petals, blossoms, shaded hearts, ribbons, lavender cats (blink and tail frames), strawberries and stars. No emoji, imported sprites or proprietary character assets. Floral sprays occupy the viewport edges at two parallax depths, with more distant particles and independent oscillations; a rare shooting heart has a short fading pixel trail.

References studied before implementation: [GO TOKYO hanami and hanafubuki](https://www.gotokyo.org/en/story/guide/the-japanese-cherry-blossom-trees/index.html); [Japan Guide cherry blossoms](https://www.japan-guide.com/e/e2011.html); [Paulo Dos Reis, Animations/sprites](https://www.behance.net/gallery/45738323/Animationssprites) for a dusk palette, silhouette framing and drifting blossoms; [pixel icon color and shading reference](https://ko-fi.com/s/73739aad12), and [pixel sprite animation technique](https://spritecanvas.com/pixel-art-animation/) for limited palettes and unsmoothed edges. Only broad artistic principles were used; all code and glyph matrices are original.

## Scope and lifecycle
The only homepage markup changes load an independent stylesheet and module. The Sofra card and mascot markup/style/behavior, links, service status and Daedalus code are unchanged. The new aria-hidden, pointer-transparent fixed layer uses the existing foreground stacking convention. Four disjoint canvas panels exclude the card with five pixels of clearance; wash is behind content. A reversible smoothstep envelope measures the Sofra section and attenuates its own effects by (1 - Daedalus wash)^2 using the existing celestial envelope formula. The Daedalus implementation remains untouched. A 112-particle fixed pool (70 on narrow screens) and capped backing scale bound work; 24/30 target paint cadence, integer backing-pixel sprite dimensions, visibility/IntersectionObserver suspension, 1x1 released buffers outside range, static reduced-motion frame, and pagehide/BFCache cleanup. No new dependencies or controls.

## Verification
Unit tests cover direction symmetry, activation, celestial suppression, nonoverlapping canvas bands, pixel budget, seeded sprites and finite poses. Dedicated CI runs Chromium, Firefox and WebKit in desktop and 390px/DPR3 configurations, captures baseline (same camera/scroll with only the overlay hidden), active, reduced-motion, leaving, celestial and return views, and checks hit-testing, static/moving frame digests, cadence, buffer release and lifecycle. The actual card regression and Daedalus smoke suites remain unchanged. A mobile WebKit emulation is not a physical iPhone test. Review CI screenshots and measurements before merge; no deployment is performed by this change.
