GOOD QUESTIONS

A little clarity.

Can I use Sofra in more than one server?

Yes. Configuration and member records are separated by server. Managing one server does not grant access to another.

Does Sofra need Administrator?

No. Permissions depend on the features you enable. Role assignment needs Manage Roles and appropriate hierarchy; moderation needs the relevant Discord permissions. Run /health for a starting check.

What does “saved” mean in the dashboard?

The configuration has reached shared storage. “Applied” means the bot acknowledged that version recently. If there is no recent acknowledgement, check bot health before assuming the change is active.

Where do I get help?

Start with /help, /setup, or /health in Discord. A server's ticket panel contacts that server's staff—not the Sofra developer. For project issues, use Sofra's issue tracker; never include tokens, passwords, or private member data.
