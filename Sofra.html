Get Sofra set up

Start with a welcome message. Turn on more features when you need them.

Choose a server

  1. Choose your community

    Sign in with Discord and pick a server you own or have Manage Server permission for. Use Add Sofra if she isn’t installed yet.

  2. Give Sofra a place to work

    Run /setup and /health. Choose welcome and staff-log channels. Keep Sofra’s role above roles she should assign.

  3. Try your settings

    Customize your welcome, test AutoMod in log-only mode, and enable tickets or levels. Save, then refresh sync status to confirm Sofra applied your settings.

Good questions

Can I use Sofra in more than one server?

Yes. Sofra keeps configuration and member records separate for each server. You need permission to manage each server individually.

Does Sofra need Administrator access?

No. Permissions depend on the features you enable. Role assignment needs Manage Roles and an appropriate role hierarchy. Moderation needs the relevant Discord permissions. Run /health to check.

What does “saved” mean in the dashboard?

“Saved” means the configuration reached shared storage. “Applied” means the bot acknowledged that version recently. If you see “saved” without “applied,” check bot health.

Where do I get help?

Start with /help, /setup, or /health in Discord. Use your server’s ticket panel to talk to its staff. You can report bot issues in Sofra’s issue tracker. Keep tokens, passwords, and member data private.
