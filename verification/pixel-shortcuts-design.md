# Animated homepage shortcuts
The Roblox Name and Logo Guidelines (https://en.help.roblox.com/hc/en-us/articles/115001708126-Roblox-Name-and-Logo-Guidelines) restrict general use of the logo and Tilt. The new profile emblem is an original block-avatar silhouette, not a modified official mark or Studio icon; the accessible link name and destination still identify Roblox. Reference: https://about.roblox.com/newsroom/2022/08/our-refreshed-logo. The closed vault uses stepped metal edges, cyan scanning and a fixed closed shackle in every pose; decorative motion does not report security state. Both use 36-unit crisp SVG artwork and 52px matching bezels. CSS steps and visibility gating follow the homepage's existing sprites and MDN animation guidance (https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/easing-function/steps). Desktop and touch reuse the current shared pointer decoration and echo, respectively. No authentication code or link destination is changed.
