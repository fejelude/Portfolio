Reference: https://about.roblox.com/newsroom/2022/08/our-refreshed-logo. The closed vault uses stepped metal edges, cyan scanning and a fixed closed shackle in every pose; decorative motion does not report security state. CSS steps and visibility gating follow the homepage's existing sprites and MDN animation guidance (https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/easing-function/steps). Desktop and touch reuse the current shared pointer decoration and echo, respectively. No authentication code or link destination is changed.
