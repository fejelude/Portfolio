# Homepage atmospheric continuity
## Root cause
The user screenshot shows a full-width dark navy band and divider between Interactives and Daedalus; the first video shows the same gap in both directions. The second recording shows Sofra's pink atmosphere continuing around its card into About. Inspection found multiple independent background owners: a fixed celestial solid fill and four canvas bands, a fixed Sofra wash with a one-sided handoff, Roblox's reading-line body color switch, commissions' clipped section wash, and the default flat body color between activation zones. The shared section border made the transition conspicuous. The canvas bands excluded an additional 5–8px beyond the rounded card, leaving a visible rectangular strip. Daedalus also lacked visualViewport resize invalidation. Automotive and Interactives use local artwork rather than a separate full-page atmospheric renderer; About receives the Sofra garden tail.
## Design
Replace the competing base color fills with one continuous CSS document-space gradient anchored to the actual content geometry (including Roblox sub-scenes and all three services). Existing navy, rose, violet, green, amber and aqua are retained. Smoothstep color stops and static radial lights interpolate through the existing whitespace. The new stylesheet suppresses the redundant old fills only after the shared gradient initializes; existing no-JS/module-failure fallback remains. No new foreground overlay or particle system. Preserve decorative artwork, controls, section geometry and card backgrounds. The full-width border retains its layout pixel but is transparent across the atmosphere. Existing canvas bands extend 12px under the opaque cards, remaining disjoint and budget-capped. Decorative canvases are explicitly noninteractive.
## Performance
No scroll listener or perpetual render loop for the document gradient. ResizeObserver and viewport/font events coalesce geometry updates into one RAF. Existing canvas DPR budgets, 24/30 fps limits, visibility suspension and reduced-motion behavior remain; fast-scroll prewarm and visualViewport resize handling supplement observer gates. Services ember visibility follows the section while icon animation remains row-gated.
