# Commissions refinement
Original SVG pixel artwork, not downloaded sprites or official brand assets. The existing homepage's Violet Terminal typography, stepped framing and local IntersectionObserver gating are retained. The section's scroll wash uses bounded geometry and passive, coalesced animation frames rather than a perpetual canvas loop.

References consulted: [Roblox Studio interface](https://create.roblox.com/docs/studio/overview) and [Studio setup](https://create.roblox.com/docs/studio/setup) for blue editing identity and building stages; [Blender logo guidelines](https://www.blender.org/about/logo/) for secondary orange/blue visual identity; [Lamborghini Revuelto](https://www.lamborghini.com/models/revuelto), [Ferrari 12Cilindri design](https://ifdesign.com/en/winner-ranking/project/ferrari-12cilindri-12cilindri-spider/697334), [Rolls-Royce Spectre](https://www.rolls-roycemotorcars.com/en_GB/showroom/spectre.html) for wedge, GT and luxury coupe proportions; [pixel car artwork](https://dribbble.com/shots/23759865-Pixel-Art-Cars-NFT-Collection) for reduced side-profile silhouette and shading; [pixel UI framing](https://makepixel.ai/guide/nine-slice/) for crisp edge construction. No source artwork copied. The web scene uses original browser/editor layouts drawn on an integer grid.

Four game-building scenes, five automotive modeling studies (four original car silhouettes and a mesh study), four website-construction scenes. Each frame holds for 1.2 seconds. Art is decorative, first-frame static with reduced motion/no JavaScript, and scoped to the commissions section. The button still targets #contact. No separate service page.
